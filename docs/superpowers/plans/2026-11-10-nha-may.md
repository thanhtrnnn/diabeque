# Nhà máy Diabeque Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Real LLM fallbacks in the chapter-6 agents, a three.js candy-works observability page that plays real agent traces (live and recorded), and the KB's Cypher queries as readable `.cypher` files merged into one.

**Architecture:** Backend enriches each trace step with `code` (via `inspect`) and `fallback`, adds an outage switch and an `agent.error` frame. Frontend splits into a pure model (`lib/factory/*`: layout, route-from-trace, run reducer, runner hook) tested with vitest, and a three.js scene (`components/factory/*`) that only renders model state. Cypher files are a read copy kept honest by a drift test.

**Tech Stack:** Python 3.11, FastAPI, LangGraph, pytest; Next.js 16, React 19, vitest, three.js (`three` + `@types/three`), `next/font/google` (Baloo 2, Be Vietnam Pro).

**Spec:** `docs/superpowers/specs/2026-11-10-nha-may-observability-design.md`. Visual direction contract: `.impeccable/surfaces/chap6-agents-frontend-src-app-app-nha-may-page-tsx.md`. Product context: `PRODUCT.md`.

## Global Constraints

- All UI copy Vietnamese. Characters original; no names, characters or imagery from any film or book.
- Do not change LangGraph topology, prompts, models, or evaluation numbers. Kiến trúc page and chat UI keep working unchanged.
- New trace fields are optional on the wire: old frontends ignore them, the new parser accepts their absence.
- Simulation only when `ALLOW_SIMULATION=1` (setting `allow_simulation: bool = False`; `.env.example` sets `ALLOW_SIMULATION=1`).
- Code links: VS Code `vscode://file{repo_root}/{path}:{line}`, GitHub `https://github.com/thanhtrnnn/diabeque/blob/{commit or "main"}/{path}#L{line}`.
- Palette (direction contract): chocolate `#2a160c` / `#3b1f12`, strawberry `#ff6fa8`, lemon `#ffd23f`, mint `#6ad1e3`, sugar `#fff4e0`. Display Baloo 2, text Be Vietnam Pro.
- Station state never conveyed by color alone (shape/pattern/icon too). `prefers-reduced-motion` gets step mode.
- Existing tests stay green: `make test` (37 chap5 + 31 chap6 pytest) and `npm test` in `chap6-agents/frontend`.
- Python runs from root venv: `../.venv/bin/python -m pytest` inside each app (see app Makefiles).

## Review Focus

- Stream breaks mid-turn (network, backend restart): the factory marks the station it was waiting on as failed and frees the input; no frozen candy. Test in Task 9.
- User fires a new question or scenario while one is animating: the old run is cancelled, no ghost candy or stale captions. Test in Task 9.
- Backend restarted between turns (InMemorySaver empty) with an old `conversation_id`: turn runs as a fresh profile without errors; memory vault shows empty. Test in Task 9 (runner accepts a turn whose trace restarts intake).
- Step without `code`, unknown agent id, or tool name not in the map: renders without link, never throws. Test in Task 7 and Task 8.
- No WebGL / context lost: page shows the fallback panel with link to `/app/kien-truc` instead of a blank canvas. Test in Task 12.
